pi-configurator

Crea e aggiorna profili provider di pi-code su macOS, Linux e Windows. Si installa con una riga di comando, e non sovrascrive mai quello che hai già configurato. MITEULA v1.1

Installa

curl -fsSL https://raw.githubusercontent.com/ALF-Robotics/pi-configurator/main/install.sh | sh

Installa in ~/.local/bin. Aggiungi quella cartella al PATH se non c'è già.

irm https://raw.githubusercontent.com/ALF-Robotics/pi-configurator/main/install.ps1 | iex

Installa in %USERPROFILE%\.pi-configurator.

Pinna la versione. main può cambiare in qualsiasi momento. Per un'installazione riproducibile usa un tag: ... | sh -s -- --ref v0.2.0 Ogni file scaricato viene verificato con lo SHA256 prima di essere installato; se l'hash non corrisponde, l'installazione si ferma senza scrivere nulla.

Configura un provider

Senza una riga di comando, senza prompt, e senza scrivere la chiave in chiaro nel file di configurazione. 

pi-conf.sh add \
  --endpoint https://api.server.example \
  --api anthropic \
  --model MLR-3 \
  --key-env MLR_API_KEY \
  --yes

--key-env scrive "apiKey": "$MLR_API_KEY" nel file. Pi la risolve dall'ambiente a ogni richiesta, quindi la credenziale non finisce mai su disco in chiaro.

Oppure installa e configura nella stessa invocazione: 

curl -fsSL https://raw.githubusercontent.com/ALF-Robotics/pi-configurator/main/install.sh \
  | sh -s -- --ref v0.2.0 -- \
      --endpoint https://api.server.example --api anthropic \
      --model MLR-3 --key-env MLR_API_KEY

Cosa garantisce

ProprietàCome
Non sovrascrive Il merge è campo per campo. apiKey, promptCache, headers, compat e i cost reali restano, e i modelli sono uniti per id senza riordinare.
Backup Prima di ogni scrittura su un file esistente viene creato models.json.bak.
Anteprima sicura L'anteprima a terminale maschera la chiave: mostra •••••••• e le ultime 4 cifre.
File illeggibile Se models.json non è JSON valido, nessuna delle due implementazioni scrive: si fermano e segnalano.
Verificato 90 asserzioni coprono merge, backup, mascheramento, permessi, modalità non interattiva e installer.

Opzioni dell'installer

OpzioneEffetto
--ref <tag>Installa una versione specifica. Un tag rende l'URL immutabile.
--prefix <dir>Dove installare. Default ~/.local/bin.
--dry-runMostra il piano senza scrivere.
--no-verifySalta il controllo SHA256.
-- <args>Passa tutto il resto a pi-conf.sh.
